# Mark Machukhu — Portfolio

Personal portfolio for a product-minded software engineer. The site communicates one coherent personal brand with two audience pathways: engineering opportunities and independent product/project conversations.

## Stack

- Next.js 16 App Router
- React 19 and TypeScript
- Tailwind CSS v4 (CSS-first import and PostCSS plugin)
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Content integrity

Project summaries are intentionally conservative. Sentinel is presented as an engineering case study, RefillRadar as a product concept, and Navakholo as an earlier project archive. Detailed case studies should only claim features, outcomes and individual contributions that can be verified from the codebase and project history.
